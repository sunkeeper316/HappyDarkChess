# HappyDarkChess 歡樂暗棋

使用 Flutter 與 Flame 製作的台灣中國暗棋遊戲。目前支援玩家對電腦，以及兩位玩家在同一部裝置上輪流遊玩。

## 目前功能

- 4 × 8 暗棋棋盤與完整 32 枚棋子
- 每局開始自動隨機洗牌
- 首次翻棋決定玩家一的陣營
- 玩家對電腦模式與本機雙人模式
- 超級兵模式：紅黑雙方可各自選擇一種棋子獲得特殊能力
- 同一個 Wi-Fi 下的雙裝置連線對戰
- 翻棋、移動、吃子、回合切換與勝負判定
- 顯示目前回合及紅黑雙方剩餘棋子數
- Android、iOS、Web 與 macOS 平台專案

## 遊戲方式

1. 選擇「電腦」或「雙人」模式。
2. 第一位玩家翻開任意棋子，翻出的顏色就是玩家一的陣營。
3. 翻棋、移動或吃子都會使用一個回合。
4. 點選自己的明棋，再點選合法目的地即可移動或吃子。
5. 將對方棋子全部吃完即獲勝。

## 超級兵模式

首頁提供兩種超級兵玩法：

- 「紅黑指定」：分別指定紅方與黑方的超級棋種，維持原本玩法。
- 「玩家指定」：玩家各自選擇超級棋種，第一次翻棋決定陣營後，能力會跟著玩家而不是顏色。電腦對戰中玩家只決定自己的棋種，AI 每局自行選擇；本機雙人則由玩家一與玩家二分別指定。

所有同棋種的棋子在翻開後都會顯示金色外框與閃電標記。

| 階級 | 棋種 | 超級能力 |
| --- | --- | --- |
| 7 | 帥／將 | 像炮一樣隔一枚棋子吃兵／卒 |
| 6 | 仕／士 | 第一次吃子後，同一枚棋可立即再吃一枚；若無目標則換手 |
| 5 | 相／象 | 沿斜線隔一枚棋子吃任意敵方明棋 |
| 4 | 俥／車 | 無阻擋時沿直線任意移動或吃子；隔一枚棋子也可吃任意敵方明棋 |
| 3 | 傌／馬 | 可斜走一格，並可吃帥／將以外的敵方明棋 |
| 2 | 炮／包 | 可沿直線跳過任意數量的暗棋，吃暗棋後方的敵方明棋；路徑遇到明棋即被截斷，也可直接吃暗棋（不分敵我） |
| 1 | 兵／卒 | 可吃士／仕以外的任何敵方明棋，且仍可被正常吃掉 |

## Wi-Fi 連線對戰

1. 兩台 Android、iPhone 或 macOS 裝置連上相同的 Wi-Fi。
2. 玩家一點選「Wi-Fi 連線對戰」→「建立房間」。
3. 玩家一把畫面顯示的 IP（例如 `192.168.1.23:4040`）告訴玩家二。
4. 玩家二進入「Wi-Fi 連線對戰」，輸入該 IP 並點選「加入房間」。
5. 顯示「已連線」後，由房主先翻第一枚棋子。

房主是權威端：洗牌、合法走法與正式棋盤都由房主判斷，加入者只傳送點擊操作。連線使用區域網路 WebSocket，不需要外部伺服器或網際網路。若無法連線，請確認兩台裝置使用相同 Wi-Fi、沒有開啟訪客網路隔離，並允許 App 存取區域網路。

目前 Wi-Fi 模式不支援 Web 瀏覽器，也尚未提供自動搜尋房間、QR Code、斷線續玩與房主轉移。

## 目前採用的暗棋規則

### 棋子與大小

| 階級 | 紅方 | 黑方 | 數量（每方） |
| --- | --- | --- | ---: |
| 7 | 帥 | 將 | 1 |
| 6 | 仕 | 士 | 2 |
| 5 | 相 | 象 | 2 |
| 4 | 俥 | 車 | 2 |
| 3 | 傌 | 馬 | 2 |
| 2 | 炮 | 包 | 2 |
| 1 | 兵 | 卒 | 5 |

一般棋子只能吃掉同階或比自己低階的棋子，並有以下例外：

- 兵／卒可以吃帥／將。
- 帥／將不能吃兵／卒。
- 炮／包的吃法不比較階級。

### 移動

- 已翻開的棋子才能移動。
- 一般棋子一次只能向上、下、左、右移動一格，不能斜走。
- 不能移動到己方棋子或尚未翻開的棋子上。
- 炮／包移動到空格時，同樣只能移動相鄰一格。

### 炮／包吃子

炮與目標必須位於同一列或同一行，中間必須剛好隔著一枚棋子（明棋或暗棋皆可），才能吃掉目標。炮可以吃任何階級的敵方明棋。

## 電腦如何下棋

目前使用會預測對手下一手的戰術型 AI，每個回合依照以下方式決定：

1. 取得電腦陣營的所有合法移動。
2. 比較吃子價值、超級能力收益，以及對手下一手可能造成的最大損失。
3. 避免吃完立刻被反吃，並偏好活動空間較大的中央位置。
4. 沒有吃子時，依周圍己方掩護與敵方威脅選擇較安全的暗棋翻開。
5. 多個動作評分相同時才隨機選擇，避免每局完全固定。

因此電腦會遵守一般與超級兵規則，也會預測一手直接反擊。它目前仍不會判斷：

- 兩步以上的攻防變化
- 完整的棋子保護與交換鏈
- 長期炮架布局
- 暗棋內容的機率分布

## 修改規則後，電腦會不會知道？

玩家與電腦共用 `canMove()` 與 `legalMoves()` 判定合法走法，因此修改以下規則後，電腦會自動遵守：

- 移動方向與距離
- 棋子能否吃某個目標
- 棋子階級關係
- 炮的合法吃法

但電腦的策略不會自動理解新規則的戰術價值。例如修改棋子強弱、加入特殊技能、連續吃子、禁手或新的勝利條件時，還需要同步調整 `playComputerTurn()` 的決策與評分方式。

## 專案結構

```text
lib/
├── main.dart                       # Flutter 畫面、模式切換與狀態列
└── game/
    ├── dark_chess_game.dart        # Flame 棋盤、棋子繪製與點擊處理
    └── dark_chess_model.dart       # 棋盤狀態、規則、勝負與電腦 AI
test/
└── dark_chess_model_test.dart      # 規則測試
```

重要方法：

- `reset()`：建立棋子並洗牌。
- `tap()`：處理玩家翻棋、選棋、移動與吃子。
- `canMove()`：判斷單一步是否合法，是玩家與電腦共用的規則入口。
- `legalMoves()`：列出指定陣營的所有合法走法。
- `playComputerTurn()`：目前的電腦決策流程。
- `_finishTurn()`：切換回合並判斷勝負。

## 開發與執行

需要先安裝 Flutter SDK，然後在專案根目錄執行：

```bash
flutter pub get
flutter run
```

指定平台：

```bash
flutter run -d chrome
flutter run -d macos
```

## 檢查與測試

```bash
flutter analyze
flutter test
```

目前測試涵蓋開局棋子數量、首翻定色、兵／卒與將／帥的特殊吃法，以及炮的隔子吃法。
